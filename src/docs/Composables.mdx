# Composables

Funções reativas exportadas por `vueui-nova-kit` e usadas pelos próprios componentes.

| Composable | Para quê |
|---|---|
| `useTheme(options?)` | Tema light/dark/system — ver também [Docs / Temas](/?path=/docs/docs-temas--docs) |
| `useReducedMotion()` | `Ref<boolean>` de `prefers-reduced-motion: reduce` |
| `useSpringValue(target, opts?)` | Anima um número com mola amortecida |
| `usePointerDrag(elRef, opts?)` | Arraste por ponteiro com rubber band e velocidade |
| `useWarmTooltipGroup()` | Tooltips "aquecidos": sem atraso ao trocar de item |
