# Espaçamento

**Categoria:** Foundations

Escala `--v-space-*` (múltiplos de 4px). Alimenta **padding**, **margin**, **gap** e posicionamento via classes Tailwind `p-*`, `m-*`, `gap-*`, `px-*`, etc.

## 1. Classes funcionais

| Classe | Token | Default |
|---|---|---|
| `p-4` / `m-4` / `gap-4` | `--v-space-4` | 16px |
| `p-6` | `--v-space-6` | 24px |
| `p-8` | `--v-space-8` | 32px |

## 3. Como customizar

Ao mudar `--v-space-4`, todas as utilities `p-4`, `m-4`, `gap-4` e componentes que usam `var(--v-space-4)` actualizam juntos.
