# Switch
**Categoria:** form  
Toggle binário on/off para configurações e preferências, com thumb animado e suporte a label/descrição.

## States
Off · Hover Off · Focus Off · On · Hover On · Focus On · Pressed · Disabled Off · Disabled On.
## Motion
| Trigger | Property | Duration | Easing |
|---|---|---:|---|
| Toggle | transform/background | 160ms | standard |
| Hover | box-shadow/tint | 100ms | ease-out |
| Focus ring | box-shadow | 120ms | ease-out |
| Pressed | thumb scale | 70ms | ease-in |

Respeitar `prefers-reduced-motion`.
## Accessibility
`role="switch"`, Space/Enter para alternar, label visível, foco com anel de 2px, opacidade no disabled, área mínima 44×24px.
## Anatomy
Root (`v-switch`) → input → track → icon → thumb → label/description. Data-test-ids: `v-switch`, `v-switch-input`, `v-switch-track`, `v-switch-thumb`, `v-switch-icon`, `v-switch-label`, `v-switch-description`.
