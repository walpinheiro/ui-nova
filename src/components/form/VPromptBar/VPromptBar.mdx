# Prompt Bar
**Categoria:** form  
Barra de prompt para superfícies de IA com anexo, dictation (Voice Pill) e ação send/stop.

## States
Idle · Ready to send · Busy (stop) · Dictation recording · Disabled.
## Motion
| Trigger | Property | Duration | Easing |
|---|---|---:|---|
| Voice expand | min-width/background | spring | ease-spring |
| Busy morph | border-radius/scale | spring | ease-spring |
| EQ bars | scaleY | 600ms | ease-in-out |

Respeitar `prefers-reduced-motion`.
## Accessibility
Textarea com `aria-label`, botões com labels dedicados, `aria-pressed` no mic, `aria-busy` quando ocupado.
## Anatomy
Attach → textarea → voice pill (opcional) → send/stop action.
