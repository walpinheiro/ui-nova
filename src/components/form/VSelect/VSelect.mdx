**Categoria:** form  
Campo de seleção single-choice com label, placeholder, ícone opcional, validação e menu suspenso acessível.

## States
Default · Hover · Focus · Open · Selected · Error · Disabled.
## Motion
| Trigger | Property | Duration | Easing |
|---|---|---:|---|
| Hover | border-color/background | 120ms | ease-out |
| Focus ring | box-shadow/transform | 120ms | ease-out |
| Open | chevron rotate + panel fade/slide | 160ms | standard |
| Option hover | background | 100ms | ease-out |
| Check reveal | opacity/transform | 120ms | ease-out |

Respeitar `prefers-reduced-motion`.
## Accessibility
Combobox/listbox com `aria-expanded`, `aria-controls`, `aria-selected`, `aria-invalid` e `aria-describedby` para erros. Teclado: Tab, ↑/↓, Enter, Esc. Label via `for`/`id` ou `aria-label`.
## Anatomy
Root (`v-select`) → label → control-shell → trigger (leading icon, value, chevron) → teleported panel (options + check) → error. Data-test-ids: `v-select`, `v-select-label`, `v-select-trigger`, `v-select-value`, `v-select-chevron`, `v-select-panel`, `v-select-option-{value}`, `v-select-check-{value}`, `v-select-error`.
