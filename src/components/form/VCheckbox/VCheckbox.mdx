# Checkbox
**Categoria:** form  
Caixa de verificação para escolhas booleanas e multisseleção, com estados checked, unchecked e indeterminate.

<Canvas of={VCheckboxStories.Default} />

</script>

<template>
  <VCheckbox size="md" label="Product updates" :model-value="false" />

## States
Default · Hover · Focus-visible · Pressed · Checked · Indeterminate · Disabled · Error.
## Motion
| Trigger | Property | Duration | Easing |
|---|---|---:|---|
| Check icon | opacity/scale | 100ms | ease-out |
| Hover background | background-color | 100ms | ease-out |
| Focus ring | box-shadow | 100ms | ease-out |

Respeitar `prefers-reduced-motion`.
## Accessibility
Label associado via `<label>`, `aria-checked="mixed"` no indeterminate, Space para alternar, foco visível, área mínima 44×44px, `aria-invalid` no erro.
## Anatomy
Root (`v-checkbox`) → input nativo → box → icon → label/description → helper/error. Data-test-ids: `v-checkbox`, `v-checkbox-input`, `v-checkbox-box`, `v-checkbox-icon`, `v-checkbox-label`, `v-checkbox-description`, `v-checkbox-helper`, `v-checkbox-terms-link`.
