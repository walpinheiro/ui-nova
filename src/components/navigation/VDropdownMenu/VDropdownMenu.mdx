# Dropdown Menu
**Categoria:** navigation  
Lista de ações e navegação compacta ("Action list and compact navigation"): acesso a ações/links a partir de um único gatilho, mantendo a interface limpa e focada. Título do hero: "PRIMARY EXAMPLE — Small menu. Fast actions. Everything you need, right where you need it." Atributos: **Flexible** (ações, links e menus aninhados), **Accessible** (keyboard friendly, screen reader ready), **Modern** (limpo, consistente).

## States

## Motion
| Trigger | Property | Duration | Easing |
|---|---|---:|---|
| Hover | background/transform | 100ms | standard |
| Focus | outline/box-shadow | 100ms | standard |
| Enter/Exit | opacity/transform | 160ms | standard |

Respeitar `prefers-reduced-motion`.
## Accessibility
Semântica nativa primeiro, foco visível, labels acessíveis e teclado conforme o padrão WAI-ARIA correspondente.
