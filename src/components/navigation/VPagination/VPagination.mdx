# VPagination

**Categoria:** navigation

Controle de navegação página a página. Divide grandes volumes em páginas discretas com variantes default, compact, ellipsis e seletor de page size.

## Overview

<Canvas of={VPaginationStories.Default} />

## Anatomy

- **Previous button** — seta `‹` (ou `Prev` na variante compact)
- **Page item** — célula clicável com número
- **Active state** — página atual com fundo primary e texto branco
- **Ellipsis** — indicador `…` não-clicável para intervalos grandes
- **Next button** — seta `›` (ou `Next` na variante compact)
- **Page size** (opcional) — `VDropdownMenu` inline à direita + texto "Showing X–Y of Z results"

## Events

| Event | Payload | Descrição |
|---|---|---|
| `update:modelValue` | `number` | Página atual (1-based) |
| `update:page` | `number` | Alias semântico de troca de página |
| `update:pageSize` | `number` | Novo tamanho de página |

## Motion

| Trigger | Property | Duration | Easing |
|---|---|---:|---|
| Hover | background | 160ms | ease-out |
| Pressed | transform | 80ms | ease-in |
| Active change | background/color | 300ms | ease-in-out |
| Focus | outline | 100ms | standard |

Respeitar `prefers-reduced-motion`.

## Accessibility

- `<nav aria-label="Pagination">` como root
- `aria-current="page"` na página ativa
- `aria-label` em prev/next e em cada página
- Ellipsis com `aria-hidden="true"`
- Botões desabilitados com atributo `disabled` nativo
- Teclado: Tab entre controles, ArrowLeft/ArrowRight em prev/next, Enter na página focada
