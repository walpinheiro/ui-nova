# Segmented Control

**Categoria:** navigation  
Controle segmentado inline de escolha única entre opções relacionadas — alternativa compacta a tabs para trocar views, períodos ou ordenação.

## Overview

<Canvas of={VSegmentedControlStories.IconAndText} />

## Anatomy

1. **Container** — trilho com borda sutil e fundo `--v-segmented-bg`
2. **Segment** — opção clicável com divisórias verticais entre itens
3. **Selected indicator** — bloco deslizante com fundo azul-claro e borda brand
4. **Label** — texto do segmento
5. **Optional icon** — ícone à esquerda do label (ou sozinho em icon-only)

## Variants

<Stories />

| Variante | Uso |
|---|---|
| Text only | Day / Week / Month |
| Icon only | Lista / grade / calendário (exige `ariaLabel`) |
| Icon + text | List / Grid / Calendar |
| Pill | Light / Dark / System com radius total |

## States

Default · Hover (fundo azul-claro) · Focus-visible (anel 2px) · Pressed · Selected (indicador + texto brand) · Disabled (opacidade reduzida).

## Events

| Evento | Payload | Descrição |
|---|---|---|
| `update:modelValue` | `string` | Emitido ao selecionar um segmento |

## Motion

| Trigger | Property | Duration | Easing |
|---|---|---:|---|
| Indicator slide | `transform`, `width` | 200ms (`--v-segmented-motion`) | `ease-in-out` |
| Hover / pressed | `background`, `color` | 100ms | standard |

Respeitar `prefers-reduced-motion`.

## Accessibility

- Container: `role="radiogroup"`
- Segmentos: `role="radio"` com `aria-checked`
- Navegação por setas ←/→, Home/End
- `aria-label` no grupo (obrigatório em icon-only)
- Foco visível em cada segmento

## Do / Don't

**Do:** use labels paralelos e concisos (Day/Week/Month).  
**Don't:** use ações verbosas ("Show list view") — descreva o conteúdo, não a ação.
