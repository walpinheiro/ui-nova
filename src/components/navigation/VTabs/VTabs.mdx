# Tabs
**Categoria:** navigation  
Ajudar o utilizador a navegar entre conteúdos relacionados dentro do mesmo contexto, mantendo a informação organizada e acessível. É navegação contextual (não muda de página): alterna painéis de conteúdo relacionado (ex.: Overview/Features/Pricing/FAQ, General/Team/Billing/Integrations, Home/Analytics/Settings/Security).

## Navigation mode & actions
`panels={false}` remove o tabpanel (e o `aria-controls`), usando as tabs como navegação. O slot `#actions` renderiza no fim da barra de tabs.

## States
Default · Hover · Focus-visible · Pressed/Active quando aplicável · Disabled · Loading quando aplicável.
## Motion
| Trigger | Property | Duration | Easing |
|---|---|---:|---|
| Hover | background/transform | 100ms | standard |
| Focus | outline/box-shadow | 100ms | standard |
| Enter/Exit | opacity/transform | 160ms | standard |

Respeitar `prefers-reduced-motion`.
## Accessibility
Semântica nativa primeiro, foco visível, labels acessíveis e teclado conforme o padrão WAI-ARIA correspondente.
## Anatomy
Root → optional leading visual → content/slot → optional actions/feedback.
