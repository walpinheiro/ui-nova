# Toast
**Categoria:** feedback  
Mensagem transitória de feedback (transient feedback message) que informa ação, evento de sistema ou atualização de status de forma breve e não intrusiva. Aparece temporariamente, mantém o usuário informado e desaparece automaticamente. Promessa hero: "Deliver feedback without interruption.

## Component

## Uso
```vue
<script setup lang="ts">
import { VToast } from 'vueui-nova-kit'
</script>

<template>
  <VToast message="New updates are available." size="md" variant="info" :duration="5000" />
</template>
```

## States

## Motion
| Trigger | Property | Duration | Easing |
|---|---|---:|---|
| Hover | background/transform | 100ms | standard |
| Focus | outline/box-shadow | 100ms | standard |
| Enter/Exit | opacity/transform | 160ms | standard |

Respeitar `prefers-reduced-motion`.
