# Empty State
**Categoria:** feedback  
Estado vazio amigável para quando não há nada para mostrar: transforma momentos vazios em próximos passos úteis com ilustração, título, descrição e ação. Cobre cenários comuns (sem projetos, sem resultados, sem ficheiros, sem notificações, onboarding de criação).
